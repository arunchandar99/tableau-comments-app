# Comments App - Tableau Extension

A social media style commenting system for Tableau dashboards with rich text formatting capabilities.

## Features

- Create performance posts with rich text formatting
- Text color and highlighting support
- Comment on posts
- Delete posts functionality
- Responsive design optimized for Tableau extensions

## Usage

1. Add the `comments-app.trex` file to your Tableau dashboard
2. The extension will load the interface for creating and managing performance comments

## Files

- `comments-app.html` - Main interface
- `comments-app.js` - Application logic
- `comments-app.css` - Styling
- `comments-app.trex` - Tableau extension manifest
- `lib/tableau.extensions.1.13.0.js` - Tableau Extensions API
