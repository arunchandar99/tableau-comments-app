🚀 Deploy Your Tableau Comments App

⚠️ Important: You need a GitHub account. Sign up here if you don't have one.

Step 1: Create GitHub Repository

1. Create New Repository

2. Repository name: tableau-comments-app

3. Make it Public ✅

4. Don't initialize with README

5. Click "Create Repository"

Step 2: Deploy Your App

Open Terminal and run:

cd "/Users/arunchandar/Desktop/Tableau Extensions/comments-app"
./deploy.sh YOUR_GITHUB_USERNAME

Replace YOUR_GITHUB_USERNAME with your actual GitHub username!

Step 3: Enable GitHub Pages

1. Go to your repository on GitHub

2. Click Settings tab

3. Scroll to Pages section

4. Source: Deploy from a branch

5. Branch: main, Folder: / (root)

6. Click Save

Step 4: Use in Office

✅ Your app will be live at: https://YOUR_USERNAME.github.io/tableau-comments-app/

✅ Copy the updated comments-app.trex file to your office computer

✅ Add extension to Tableau using the TREX file
